About Laravel

Laravel adalah framework PHP untuk membangun aplikasi web dengan struktur kode yang rapi dan fitur yang lengkap.

Dokumentasi resmi: https://laravel.com/docs

Cara Menjalankan Project
1. Install Dependency
bash
composer install

2. Siapkan File Konfigurasi

Salin file .env.example menjadi .env, kemudian sesuaikan konfigurasi database di dalamnya.

3. Buat Application Key
bash
php artisan key:generate

4. Jalankan Migrasi Database
bash
php artisan migrate

5. Jalankan Server Lokal
bash
php artisan serve


Buka alamat berikut di browser:

http://127.0.0.1:8000
